Hello! Thank you for checking out MacroCalc. MacroCalc is a simple food logger written in python.
As of now it runs in the terminal but eventually (when I get around to it) I would like to add a gui.
Within this repo there are three files, the main program macro_calc.py, foods.csv which is a dataset with 60 foods, and test_macro_calc.py which is a test program using pytest.
The user can log foods that they ate in a given day and the total calories and macro nutrients will be logged to a file titled foodlog.txt
I hope that you can enjoy this project of mine
